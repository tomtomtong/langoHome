Video Pairs

Upload loop and transition videos in pairs, each with a time window, session prompt, and optional avatar background. Text and time changes save automatically; media uploads save when you upload. The voice app picks one pair at random within the current time window (using the schedule timezone below). At conversation start, the system prompt (Voice Settings) and this pair’s session prompt are combined and sent to Inworld. Its background image is used behind Uncle Tommy during the conversation.

Schedule timezone

Start and end times below use 24-hour format (HH:MM, e.g. 08:00, 20:30). Pair windows are evaluated in this timezone, not each visitor’s local clock.

Import from CSV

Bulk-create pairs from a spreadsheet. Columns: session_prompt, theme (default, warm, cool, nature, night), timezone (optional IANA name, e.g. Asia/Hong_Kong), start_time, end_time (24-hour: 08:00, 20:30, 0800, or 20:30:00), loop_video_link, transit_video_link, bg_image_link (public http/https URLs; downloaded on import).
